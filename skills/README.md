# Skills

Reusable agent skills will live here.

A skill is a short Markdown file that teaches an agent one repeatable task, for example "write a HANDOVER.md from a feature idea" or "run the security gate on a PR".

Planned format, one folder per skill:

```
skills/
  <skill-name>/
    SKILL.md      # when to use it, steps, done criteria
    examples/     # optional input and output samples
```
