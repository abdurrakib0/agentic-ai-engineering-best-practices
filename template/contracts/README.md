# Contracts

For projects with an API. Define every endpoint, request and response here before writing code, as shared zod schemas ([practice 02](https://github.com/abdurrakib0/agentic-ai-engineering-best-practices/blob/main/practices/02-shared-api-contracts.md)) or `openapi.yaml`, whichever fits your stack. Code in `api/` must match these files. Change a contract only together with the spec.

Delete this folder if the project has no API.
